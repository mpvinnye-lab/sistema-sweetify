# Doce Caixa PWA

Aplicativo web instalável para iPhone e Android.

## Para usar no iPhone
1. Hospede esta pasta em um endereço HTTPS.
2. Abra o endereço no Safari.
3. Compartilhar → Adicionar à Tela de Início.

Os dados são salvos localmente no aparelho (localStorage + IndexedDB). Use Exportar backup para trocar de aparelho ou manter uma cópia extra.
